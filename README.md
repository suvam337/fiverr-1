# Full-Stack MERN E-Commerce & SaaS Platform

This repository contains the complete, production-ready Full-Stack MERN E-Commerce web application.

## 📂 Project Organization

- **`E-Commerce/`**: The standalone, self-contained project directory with all client components, Express REST APIs, seed data, TypeScript configurations, and setup scripts.
- **Root**: Configured for Google AI Studio Cloud Run live preview and deployment.

---

## 💻 Running Locally on Your Laptop

To clone and run the project locally:

```bash
# 1. Clone this repository
git clone <YOUR_GITHUB_REPO_URL>

# 2. Enter the E-Commerce directory
cd E-Commerce

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Then open `http://localhost:3000` in your web browser. See `E-Commerce/README.md` for full documentation and API endpoint specifications.
